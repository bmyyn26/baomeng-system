# 寶萌 LINE Bot 部署說明

完成後，從任何手機或電腦的 LINE 傳訊息給 Bot，都能查客戶、建客戶、開訂單。

---

## 總覽步驟

```
第一步：建立 Supabase 雲端資料庫（免費）
第二步：設定 LINE 官方帳號與 Developer 後台
第三步：部署到 Render.com（免費雲端主機）
第四步：匯入現有 Excel 資料
```

---

## 第一步：建立 Supabase 資料庫（約 5 分鐘）

1. 前往 [https://supabase.com](https://supabase.com) → **Start your project**
2. 用 Google 帳號登入
3. 點 **New project**，填寫：
   - Project name：`baomeng`
   - Database Password：設一個密碼（記下來）
   - Region：選 **Southeast Asia (Singapore)**
4. 等待約 2 分鐘建立完成
5. 建立後，進入專案 → 左側選 **SQL Editor**
6. 將 `supabase_schema.sql` 的內容全部貼上 → 點 **Run**
7. 看到 `Success` 表示資料表建立完成

**取得金鑰：**
- 進入專案 → 左側 **Project Settings** → **API**
- 複製 `Project URL`（這是 SUPABASE_URL）
- 複製 `anon public`（這是 SUPABASE_KEY）

---

## 第二步：設定 LINE 官方帳號（約 10 分鐘）

**2-1 建立 Messaging API Channel：**

1. 前往 [https://developers.line.biz](https://developers.line.biz) → 用 LINE 帳號登入
2. 點 **Create a new provider** → 輸入名稱（如「寶萌」）
3. 點 **Create a new channel** → 選 **Messaging API**
4. 填寫資料：
   - Channel name：寶萌管理系統
   - Channel description：客戶與訂單管理
   - Category / Subcategory：任意選
5. 同意條款 → 建立

**2-2 取得金鑰：**

- **Channel secret**：Basic settings 頁面 → 複製
- **Channel access token**：Messaging API 頁面 → 點 **Issue** → 複製

**2-3 關閉自動回覆：**

- 到 [https://manager.line.biz](https://manager.line.biz) → 選你的官方帳號
- 設定 → 回應設定 → **自動回應訊息** 設為「停用」
- **Webhook** 設為「啟用」

---

## 第三步：部署到 Render.com（約 10 分鐘）

> Render 免費方案足夠使用，但閒置 15 分鐘後會休眠，第一次回應約等 30 秒。
> 如需 24 小時不休眠，可升級付費方案（約 $7/月）。

**3-1 準備 GitHub 儲存庫：**

1. 前往 [https://github.com](https://github.com) 登入（或註冊）
2. 點右上角 **+** → **New repository**
3. 名稱：`baomeng-line-bot`，選 **Private** → 建立
4. 將 `line_bot` 資料夾裡的所有檔案上傳到這個 repo
   （拖曳上傳即可，不需要 git 指令）

**3-2 部署到 Render：**

1. 前往 [https://render.com](https://render.com) → 用 GitHub 帳號登入
2. 點 **New** → **Web Service**
3. 選 **Connect a repository** → 選 `baomeng-line-bot`
4. 設定：
   - Name：`baomeng-line-bot`
   - Region：Singapore
   - Branch：main
   - Runtime：**Python 3**
   - Build Command：`pip install -r requirements.txt`
   - Start Command：`gunicorn app:app`
   - Instance Type：**Free**
5. 點 **Advanced** → **Add Environment Variable**，逐一加入：

   | Key | Value |
   |-----|-------|
   | `LINE_CHANNEL_ACCESS_TOKEN` | 剛才複製的 token |
   | `LINE_CHANNEL_SECRET` | 剛才複製的 secret |
   | `SUPABASE_URL` | 剛才複製的 URL |
   | `SUPABASE_KEY` | 剛才複製的 anon key |

6. 點 **Create Web Service** → 等待部署（約 3-5 分鐘）
7. 部署完成後，複製你的網址，例如：
   `https://baomeng-line-bot.onrender.com`

**3-3 設定 LINE Webhook：**

1. 回到 LINE Developers Console → 你的 Channel → **Messaging API**
2. 找到 **Webhook URL** → 填入：
   `https://baomeng-line-bot.onrender.com/callback`
3. 點 **Verify** → 看到 **Success** 表示連線成功

---

## 第四步：匯入現有 Excel 資料（約 5 分鐘）

在你的電腦上執行（需要 Python 3.8+）：

```bash
# 進入 line_bot 資料夾
cd line_bot

# 安裝套件
pip install -r requirements.txt

# 設定環境變數（把值換成你自己的）
# Windows PowerShell：
$env:SUPABASE_URL="https://你的專案.supabase.co"
$env:SUPABASE_KEY="你的_anon_key"

# 執行匯入
python import_data.py
```

> 如果 Excel 檔案路徑不對，請開啟 `import_data.py`，
> 修改第 44-46 行的 `MEMBERS_FILE`、`BLACKLIST_FILE`、`ORDERS_FILE` 路徑。

## 使用方式

加入你的 LINE 官方帳號後，直接傳文字：

| 指令 | 說明 |
|------|------|
| `說明` | 查看所有指令 |
| `查客戶 爆爆龍王` | 依暱稱查客戶 |
| `查客戶 0912345678` | 依電話查客戶 |
| `新客戶 王小明 0912345678 007-12345 王大明` | 新增客戶 |
| `買鑽 爆爆龍王 10000` | 建立買鑽訂單 |
| `賣鑽 爆爆龍王 5000` | 建立賣鑽訂單 |
| `查訂單 爆爆龍王` | 查最近10筆訂單 |
| `黑名單 爆爆龍王` | 查詢是否黑名單 |

## 常見問題

**Q：傳訊息沒有回應？**
- 確認 Render 服務有在運行（沒有顯示 error）
- 確認 Webhook URL 有設定且 Verify 成功
- 免費方案休眠後第一次回應需等 30 秒

**Q：免費方案夠用嗎？**
- Supabase 免費方案：500MB 資料庫，足夠數萬筆資料
- Render 免費方案：每月 750 小時，三人以內使用完全足夠

**Q：多人可以同時使用嗎？**
- 可以，只要都加這個 LINE 官方帳號的好友即可
- 也可以建立 LINE 群組，把 Bot 加進群組
